# epicode_groupweek1

Progetti di gruppo (build week) svolti durante un corso di cybersecurity.
I lavori sono organizzati in due cartelle, una per build week.

## BuildWeek1

Progetto di rete e scripting Python in ambiente di laboratorio.

| File | Descrizione |
|------|-------------|
| `PROGETTO TEAM BUILD .pdf` | Report del progetto di gruppo |
| `Rete Theta.pkt` | Topologia di rete realizzata con Cisco Packet Tracer |
| `catturaSocket.py` | Server TCP in ascolto su socket per accettare connessioni |
| `sniffer.py` | Server TCP su socket per la ricezione dei dati |
| `scanPorte.py` | Port scanner: controlla un range di porte su un host indicando aperte/filtrate/chiuse |
| `invioRichieste.py` | Invio di richieste HTTP GET/POST con output tabellare (uso di un proxy locale) |

## BuildWeek2
